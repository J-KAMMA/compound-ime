# コンパウンドIME（CompoundIME）

Windows 用の日本語入力ソフトです。[Mozc](https://github.com/google/mozc) の入力部分と、[MyIME](https://github.com/unok/myime) が組み込んだ azooKey／Zenzai（パソコンの中だけで動く小さな言語モデル）による変換を土台に、日本語と英語が混ざる文章を打ちやすくしました。

> コンパウンドIMEは Mozc をもとにしていますが、Google とは関係がなく、Google が推奨するものでもありません。

> **試用版です。** 作者のパソコン（Windows 11 x64）でしか動作を確かめていません。問題があれば[課題欄](https://github.com/J-KAMMA/compound-ime/issues)で教えてください。

## できること

- **ローマ字のまま英単語を打てる**：`tomato` や `meeting` のような英単語は、かなに化けずにそのまま残ります。日本語の部分だけが変換されます。
- **ブランド名などを正しい表記に**：小文字で打っても、`iPhone`・`YouTube` のような正式な表記を1位に、打ったとおりの形を2位に出します。
- **前後の文章を見て変換**：入力欄にすでにある文章を参考に、同音語を選びます。
- **人工知能の待ち時間に上限**：人工知能の答えが遅いときは0.7秒でふつうの変換に切り替えるので、パソコンが重くても入力が止まりません。
- **学習の暴走を防ぐ**：単語だけで一度選んだ候補が、文の中で勝手に1位になり続けることを防ぎます。
- **明るい／暗いテーマ**：候補ウィンドウと入力モード表示が Windows の配色に合わせて切り替わります。
- **打ち間違いの補正**：1文字の打ち間違いで読めなくなったローマ字を直します。

## プライバシー

- 変換はすべてパソコンの中で行います。打った文字を外部に送ることはありません。
- インターネットに接続するのは、インストール時に変換モデル（zenz-v3.2-small）を公式の配布元から取得するときだけです。
- 打った読みと選んだ候補の記録（変換の直し方の記録）は、**既定では保存しません**。改善のために残したい場合だけ、レジストリ `HKEY_CURRENT_USER\Software\CompoundIME` に DWORD 値 `CorrectionLogEnabled` = 1 を作ってください。

## 動作環境

- Windows 11（64 ビット、x64）で動作を確かめています。

## インストール

1. リリースのページから `CompoundIME_<版>_x64.msi` を取得して実行します。
2. インストール中に変換モデルを公式の配布元から取得します（約 74MB）。
3. 入力方式の切り替え（Windows キー＋スペース）で「コンパウンドIME」を選びます。

インストーラーには署名がないため、初めて実行するときに「発行元不明」の警告が出ます。配布ページの `SHA256SUMS.txt` でファイルが同じことを確かめてから実行してください。

公式の Mozc と並べて入れられるよう、識別子・フォルダ・サービス名などをすべて分けています（同時に入れた状態での確認はまだです）。

### 以前の開発版（Mozc の名前のもの）から移る場合

学習データと設定は `tools/migrate-to-compound-ime.ps1` で写せます。何も書き換えずに内容を確かめるには、引数なしで実行します。実際に写すときは `-Apply` を付けます。

## ソースからのビルド

`tools/apply_jaen_integration.py` が、MyIME の Mozc ソースツリーに日英判定・辞書・変換の改良と名前の変更をすべて適用します。ビルドの手順は [BUILD.md](BUILD.md) にあります。
