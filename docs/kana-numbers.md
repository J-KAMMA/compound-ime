# かなで打った数＋単位は算用数字を先頭にする（2026-10-24）

利用者の決定: かなで打った数（漢語の数詞）に単位が続くとき、算用数字を先頭の候補にする
（全員に効く既定の動き）。例: にひゃっぷん → 200分、さんぜんえん → 3000円、
じゅうにん → 10人、じゅっぷん・じっぷん → 10分、ななじゅっさい → 70歳、
じゅういちがつ → 11月、にせんにじゅうろくねん → 2026年。

## 決め方

`native/jaen-detector/jaen_number.cc` の `FindNumbers` が、かなの読みから数の部分と
単位の漢字を見つけ、`10人`、`3000円`、`2026年` のような値を作る。

| 読み | 取るか | 理由 |
|---|---|---|
| 二つ以上の部分からなる数＋単位（にひゃく、さんびゃく、ろっぴゃく、はっせん、さんぜん、にせんにじゅうろく） | 取る | 数としてほぼ紛れない |
| じゅう（10）＋単位 | 取る | じゅうにん → 10人 は利用者の決定 |
| 促音の いっ・ろっ・はっ・じゅっ・じっ ＋単位（いっぷん、ろっぴき、はっさつ、じゅっぷん、じっぷん） | 取る | 音の変わる読みを数として読む |
| ふつうの1けた＋単位（に、さん、ろく、いち ...） | 取らない | にほん（日本）、くじ（籤）、いちにち（一日）、いちど（一度）と紛れる。三人・六時・三匹は漢字のまま |
| ひゃく・せん だけの数＋単位（ひゃくえん、せんえん） | 取らない | 百姓・千葉・仙台・先輩と紛れる。にひゃく・さんぜん のように数が複数の部分からなれば取る |
| 和語の日の言葉（ついたち、ふつか、みっか、はつか ...） | 単独では取らない | ふつか → 二日、ついたち → 一日。月のあと（ごがつむいか → 5月6日）と、十の付く日（にじゅうよっか → 24日）だけ取る |
| 数の形をした普通の言葉 | 取らない | 十分、一緒、一度・一番・一部・一般・一応、三日坊主、百姓、千葉、万一、八百屋、四季 など |

単位は 分・円・人・個・本・杯・匹・回・階・歳・年・月・日・時・秒・件・枚・冊・台・点・度・倍・割・番
のほか、週間・か月・時間・日間・番目・回目・人前・パーセント。音の変わる読みとして
ひゃく→ひゃっ/びゃく/ぴゃく、せん→ぜん、ふん→ぷん、ほん→ぼん/ぽん、ひき→びき/ぴき、
はい→ばい/ぱい、さつ、てん、わり、ぶん も見る。

### 紛れる読みの扱い

- 回と階はどちらも「かい」なので回にする（既存の動き）。
- 倍は「ばい」、杯は「はい・ぱい」にする。さんばい（3杯/3倍）は倍になる。
  「ばい」を杯にしたいときは F10（打った文字のまま）か候補の選択で直す。
- ぶん は分にするが、じゅうぶん（十分）は普通の言葉なので取らない。
- 実験（じっけん）、実際（じっさい）、発展（はってん）、発見（はっけん）、一見（いっけん）、
  一転（いってん）、従妹（じゅうまい）、従事（じゅうじ）、重大（じゅうだい）、重度（じゅうど）、
  重版（じゅうばん）、充填（じゅうてん）、重点（にじゅうてん）は、単位まで含めた読みが
  数＋単位と同じになるので、数の形の普通の言葉として取らない（`IsOrdinaryNumberWord`）。

## どこで候補の順を変えるか

1. `converter::Converter::MarkEnglishSpans`（`tools/apply_jaen_integration.py`）が、
   日本語の部分を `FindNumbers` に掛け、数の部分を `Segment::FIXED_VALUE` の文節にして
   `PutTypedValueFirst` で `10人` を先頭の候補にする。前後の日本語はこれまでどおり変換する。
2. Mozc の書き換え（`rewriter/number_rewriter.cc` など）のあと、`MarkEnglishSpans` が返した
   数の文節を鍵で見つけ、もう一度 `PutTypedValueFirst` で先頭に戻す。人工知能（Zenzai）の
   全文の候補が漢数字にしても、この段で算用数字が先頭になる。
3. 打った算用数字そのもの（`980` → 九百八十）は `native/jaen-detector/typed_digits.inc` の
   `PreferTypedDigits` が戻す（docs/decimal-point.md）。今回のかなの数はこの道ではなく 1・2 で直す。

助詞の「に」のあとの数（ここにじゅうにん → ここに10人）は、直前が助詞（は・が・を・に・で・と・も・へ・や・の）か
区切りでなければ「に」を数の一部にしない（`ParticleNi`）。これで「ここにじゅうにん」が20人にならない。
「きょうはにじゅうにん」（20人）のように助詞のあとに数が続く形は、これまでどおり20人になる。

`MYIME_NUMBERS=0` で、かなの数を数字にする動き全体を止められる。

## 試験

- 単体: `native/jaen-detector/jaen_number_test.cc`（239 件）。`tools/run_tests.sh` の組 `s` が
  `g++` で組み立てて動かす。
- 変換: `tests/conversion/kana-numbers.tsv`（236 文、数＋単位は算用数字が正解）と
  `kana-numbers-ja.tsv`（208 文、和語と数の形の普通の言葉は漢字が正解）。文は
  `tools/make_kana_number_tests.py` で作る。組 `s` が数字の設定が半角のときと既定のとき、
  変換して確定する形で流し、`tools/score_decimal.py` で数字の並びを見る（かなの試験は
  入力中の表示がかなのままなので、入力中にそのまま確定する形は流さない）。
- 既存の `tests/conversion/decimal.tsv` も、にじゅうねん → 20年、よんじゅっぷん → 40分 に
  合わせて作り直した。三人・六時・百円・三匹・一人前は漢字のまま。

## 確かめていないこと

- 手元に Mozc と人工知能の重みがないので、本物の Mozc を通る組 `s` は GitHub で流す。
  一緒に日本語の組 `a1`・`b`・`h` も流して、既存の文が変わらないことを見る。
- 画面側（Windows の入力中の表示）と、Zenzai が漢数字の全文を出した場合の実際の候補の並び。
- 文脈で決まる紛れ（にじ → 虹/2時、ごじ → 誤字/5時、じゅうじ → 従事/10時 など）は、
  数として取らないか、取っても Mozc の候補選択に任せる。今回の決定の範囲外。
- 名詞のすぐあとに助詞を挟まずに数を続ける形（りんごにじゅうこ = りんご二十個）は、
  「に」を助詞とみて 10個（じゅうこ）寄りになることがある。助詞を挟む形
  （りんごがにじゅうこ）は 20個 になる。
